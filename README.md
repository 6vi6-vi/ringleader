# Ringleader

## Описание
Веб-приложение для организации и проведения выставок собак. Позволяет регистрировать питомцев, подавать заявки на участие, управлять клубами и фиксировать результаты выступлений.

## Функциональность

- Регистрация и авторизация пользователей
- Три роли: гость, пользователь, администратор
- Управление собаками (добавление, редактирование, удаление, фото)
- Каталог пород и клубов с фильтрацией
- Создание и управление выставками 
- Подача заявок на участие в выставках
- Модерация заявок (одобрение/отклонение)
- Фиксация результатов по породам
- Просмотр победителей на главной странице
